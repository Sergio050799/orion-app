# Files of Truth (Definitive Locations)

This registry defines the single source of truth for all project data. DO NOT modify these files unless authorized.

## 1. Normativa (Markdown)
**Location**: `src/core/_source_of_truth/normativa_md/`
- Contains all `.md` files describing the regulations (Manual de Reformas, etc.).

## 2. Dictionaries (JSON)
**Location**: `src/core/_source_of_truth/dictionaries/`
- `itv_master_dictionary.json` (V1 Source)
- `normativa_unificada.v1.json` (Source)
- `itv_master_dictionary.v2.json` (V2 Source)

## 3. License Plates (Reference Data)
**Location**: `src/core/_source_of_truth/plates/`
- Contains year/month mapping JSONs.
- Contains implementation guides for plate resolution.

## 4. References (Assets)
**Location**: `src/core/_source_of_truth/references/`
- Reference PDFs, guides, and assets.
- `schema_versioning.md`
- `types.md`
